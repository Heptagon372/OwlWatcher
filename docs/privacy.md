# 개인정보 처리방침 (초안)

설계서 10장의 코드판이다. **이 문서에 없는 것은 코드에도 없어야 한다** — 그 반대가 아니라.
확인 방법도 함께 적는다. "안 한다"는 약속은 검증할 수 있어야 약속이다.

> 초안이다. 학교 개인정보 보호책임자 검토 전에는 실제 시험에 쓰지 않는다.

---

## 1. 수집하는 것

| 항목 | 신호 | 왜 필요한가 |
|---|---|---|
| 실행 파일 경로 (홈 디렉터리는 `~` 로 치환) · SHA-256 해시 · 서명자 · 부모 pid · 시각 | S1 · S9 | 허용목록 밖 프로세스를 이름이 아니라 신원으로 대조한다 |
| 상태 영역(트레이) 항목의 소유 프로세스 | S2 | 아이콘 모양이 아니라 소유자가 근거다 |
| 창의 캡처 공유 상태 (**창 제목 아님**) | S3 | 캡처에서 빠진 창이 있는지 |
| Caps Lock 상태가 뒤집힌 시각 | S4 | 주기의 규칙성만 본다 |
| HID 장치를 연 사실 | S12 | LED 신호 채널 |
| 네트워크 인터페이스 수 · 비콘/카나리 도달 여부 · 프로세스별 원격 host:port | S5 | 시험망 안에 있는가 |
| 가상머신 여부 (CPUID · SMBIOS) | S6 | 시험 정책 위반 여부 |
| 캡처 차단 자가검증 결과 · 에이전트 자기 서명 검증 결과 · 하트비트 서명 | S8 · S13 · S14 | 보호가 지금도 유효한가 |

## 2. 수집하지 않는 것

- **키 입력** — 어떤 키를 눌렀는지는 알 수 없고, 알 수도 없다
- **화면 내용 · 스크린샷 · 창 제목**
- **클립보드 · 파일 내용 · 파일 목록**
- **브라우저 방문 기록**
- **카메라 · 마이크**
- **위치 · Wi-Fi SSID** — 시험망 여부는 비콘 도달로 판단한다
- **학생 이름** — 좌석 번호와 학번 해시만 쓴다
- **실행 인자(argv) · 환경변수** — 명령줄에 담긴 내용이 새지 않도록

### 이걸 어떻게 확인하나

수집 범위는 **OS 에 무엇을 묻는지**로 결정된다. 그 목록이 코드에 상수로 박혀 있다.

- Windows: [`Native.cs`](../agent-windows/src/OwlWatch.Collectors/Native.cs) 의 P/Invoke 선언 전부.
  키 입력 후킹(`SetWindowsHookEx`), 클립보드(`OpenClipboard`/`GetClipboardData`),
  파일 열람 API 가 **없다**. 화면 캡처(`BitBlt`)는 있지만 대상이 우리 시험 창의 센티넬 띠뿐이다.
- macOS(예정): ES 구독 목록. `AUTH_*` 와 `NOTIFY_OPEN`/`WRITE`/`READDIR`(파일 내용 계열)은 구독하지 않는다.

에이전트 소스를 공개한다. "무엇을 안 하는지"를 코드로 증명하는 가장 싼 방법이고,
허용목록·임계값은 서버 정책이라 공개해도 손실이 적다.

## 3. 동의

- 응시 전 화면에서 위 두 표를 **그대로** 보여주고 동의를 받는다
  ([`ConsentForm.cs`](../agent-windows/src/OwlWatch.Runtime/Ui/ConsentForm.cs))
- **동의하지 않으면 아무 관측도 만들지 않고 종료한다** (종료 코드 4)
- L1 설치에 관리자 권한이 필요한 이유와 제거 방법을 같은 화면에 적는다
- 근거: 개인정보보호법 제15조(동의) · 제16조(최소 수집) · 제30조(처리방침)

## 4. 학생이 보는 것

감독관이 보는 것과 **같은 형식·같은 등급**으로 학생도 본다. 감독관에게만 보이는 화면은 없다.

- 시험 중: 에이전트 오른쪽 상태창에 전송된 이벤트가 실시간으로 뜬다
- 시험 후: `내 기록 내보내기` 로 자기 세션 로그를 JSON 으로 받는다
  (P0/P1/P2 가 섞이지 않게 세 절로 나뉜 증거 번들)

## 5. 보관과 삭제

| | |
|---|---|
| 기본 보관 | **30일** |
| 연장 | 이의제기가 진행 중인 세션만 |
| 저장 위치 | 학생 기기 `%LOCALAPPDATA%\OwlWatch\<세션>\events.jsonl` + 콘솔 |
| 삭제 | 보관 기간이 지나면 자동. 삭제도 감사 로그에 남는다 |
| 세션 키 | 시험이 끝나면 즉시 삭제 (TPM 키 · 소프트웨어 폴백 키 모두) |

리전은 서울로 고정해 국외이전 쟁점을 피한다(콘솔 구축 시).

## 6. 이 도구가 하지 않는 것

- **부정행위를 판정하지 않는다.** 확인 요청을 만들고 증거를 보관할 뿐이고, 처분은 사람과 위원회가 한다.
- **P1 을 사실처럼 쓰지 않는다.** 리포트는 P0(확인된 사실) / P1(정황) / P2(참고)를 절대 섞지 않고
  세 절로 출력한다. 이건 문서 관례가 아니라 코드로 강제된다
  ([`EventStore.ExportBundle`](../agent-windows/src/OwlWatch.Runtime/EventStore.cs)).
- **얼굴 인식 · 시선 추적 · 룸 스캔을 하지 않는다.** 범위는 "노트북 상주 도구"로 고정.

## 7. 남은 검토 사항

- 학번 해시의 솔트 관리 — 학기 단위 폐기 여부 (설계서 14장 미결 7번)
- 기기 지문·하드웨어 키 공개키의 보관 범위 — 학기 단위 vs 시험 단위
- 이의제기 절차에서 증거 열람 권한을 누구에게 줄 것인가
- 학칙 문구 제안서 (미작성)
